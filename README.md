# VAST Builders Challenge

Starter repo for the VAST Builders Challenge build day. Build a video agent on top of a
pre-running video understanding + search stack, all from Cursor.

- **Start here:** [BUILD_DAY.md](./BUILD_DAY.md) — the guide for the day.
- **Skills:** `.cursor/skills/` — Cursor agent skills that drive the stack (ingest,
  search, ask). Open this repo in Cursor and just describe what you want.

> Work in progress. Sections and skills are being filled in.
